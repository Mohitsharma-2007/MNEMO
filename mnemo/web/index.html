GITHUB API

Why a token can help

A GitHub token is optional. Cloning and local source analysis work without one; the token only raises the REST API rate limit so bounded contributor, pull request, issue, and release collections are less likely to be partial.

Without a tokenMnemo still analyzes the checkout and reports any unavailable API collections honestly.
With a tokenSet GITHUB_TOKEN in .env or the server process. It never reaches the browser.
